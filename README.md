# Lee Buyong · L&D Operations Portfolio

교육 인력 운영의 흐름을 더 명확하게 만드는 L&D/HRD 실무자 **이부용(Lee Buyong)**의 개인 포트폴리오 웹사이트입니다.
강사·기술튜터 지원자 관리부터 온보딩, 현장 투입 안내, 운영 기준 문서화까지의 실무 경험을 담았습니다.

🔗 **Live** — https://leebuyong.github.io/portfolio_LnD/

## 소개

단순한 경험 나열이 아니라, 교육 인력이 역할에 빠르게 적응할 수 있도록 **사람과 프로세스를 연결하는 운영 방식**을 보여주는 것을 목표로 제작했습니다.

- **Applicant Operations** — 지원자 서류 검토, 진행 현황 트래킹, 후보자 리스트업·컨택, 안내 메일 발송
- **Onboarding Design** — 내부/외부 인력을 구분한 온보딩 정보 구조 설계 및 웹페이지 제작
- **Deployment & Quality Support** — 파일럿 배정, 현장 투입, 운영 이슈·아웃보딩 기준 관리
- **Documentation System** — R&R·가이드·회의록·트래킹 문서를 통한 운영 체계 구조화

## 기술 스택

- **HTML · CSS · Vanilla JavaScript** (외부 프레임워크 없이 단일 파일로 구성)
- **Typography** — Fraunces(디스플레이) · Pretendard(한글 본문) · Inter(라벨·숫자)
- **Design** — 다크 에디토리얼 톤, 장식 원호·등록 마크, 절제된 모션
- **인터랙션** — 스크롤 진행 바, 스크롤스파이 내비게이션, 모바일 풀스크린 메뉴, 스크롤 리빌, 카운트업 (`prefers-reduced-motion` 대응)

## 파일 구조

```

├── index.html      # 포트폴리오 본문 (단일 파일)
```
